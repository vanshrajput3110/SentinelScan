# Submission checklist

- [ ] Add your name, course, institution, supervisor, and submission date if required.
- [ ] Install dependencies in a clean virtual environment.
- [ ] Run `python -m unittest discover -s tests -v` and confirm all tests pass.
- [ ] Run a scan only against a site you own or have permission to test.
- [ ] Open `reports/scan.html` and verify the report renders correctly.
- [ ] Capture screenshots of terminal output and the HTML report from your own run.
- [ ] Review the README and be ready to explain each check and its limitations.
- [ ] Confirm your institution's required report format, declaration, and plagiarism policy.
- [ ] Do not submit illustrative output as if it came from a real scan.
